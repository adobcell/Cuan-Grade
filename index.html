Fungsi setiap menu

Gunakan tombol menu utama sesuai pekerjaan.

🧾 Transaksi pembelian limbah

  • Tambah item kiloan atau satuan.
  • Hitung subtotal, total Kg/Pcs, dan total pembayaran.
  • Ubah/hapus item pada keranjang dan kosongkan transaksi.
  • Lihat struk, cetak, atau bagikan teks nota ke WhatsApp.

🔬 Scanner & database IC

  • Scan dari kamera, upload foto, atau pilih contoh.
  • Lihat kandidat hasil OCR dan cari berdasarkan part number.
  • Tambah, edit, atau hapus data IC; simpan alias OCR.
  • Hubungkan IC ke nota beli scrap.

🔧 Servis HP

  • Form penerimaan unit, data pelanggan, WhatsApp, model, IMEI opsional, kondisi, dan keluhan.
  • Nomor servis otomatis, teknisi, status, persetujuan biaya, catatan, jasa, spare part, uang muka, sisa tagihan, dan garansi.
  • Riwayat bisa dicari; nota demo dapat dibuka ke WhatsApp, dibuat sebagai gambar, atau dicetak.
  • Data prototipe servis tersimpan lokal di browser/perangkat.

🏷️ Katalog harga patokan limbah

  • Lihat referensi harga barang yang dibeli.
  • Tambah item baru dan perbaiki nama, satuan, atau harga.
  • Pilih item katalog untuk mengisi transaksi.

⚙️ Pengaturan toko & printer

  • Atur nama toko, alamat, nomor telepon, dan footer struk.
  • Pilih target printer sesuai opsi yang tersedia.
  • Konfigurasi link Google Sheet dan URL Apps Script Web App.
  • Lihat/salin template Code.gs untuk Apps Script.

🔑 API key OCR

  • Pilih mode OCR yang tersedia.
  • API key online disimpan otomatis pada perangkat setelah input berhenti sesaat.
  • Periksa indikator status key sebelum melakukan scan online.

🎨 Tema, lisensi, dan keluar

  • Pilih tema tampilan dari tombol tema.
  • Lihat status lisensi dan identitas perangkat.
  • APK Member: Keluar mereset sesi lisensi dan kembali ke layar aktivasi; data transaksi tetap tersimpan.
  • APK Admin tidak memakai login member; Keluar menutup aplikasi.
Nota pembelian dari penjual

Satu-satunya jenis nota di aplikasi. Setiap nota punya nomor otomatis (#SCRAP-YYMMDD-001), draft tersimpan otomatis, riwayat tersimpan di perangkat (menu Riwayat Nota), dan dicatat satu baris per nota ke Google Sheets bila Apps Script sudah diatur.

Data disimpan di mana?

Data lokal tetap di perangkat; berkas backup disimpan di lokasi yang dipilih pengguna.

Alur teknis halaman dashboard

DashboardActivity membuka halaman aset scrap_engine.html ke WebView dan menyediakan AndroidBridge untuk fitur Android seperti kamera, kontak, API key, WhatsApp, dan pemilih berkas.

Alur teknis scanner

Foto/gambar → OCR Android atau layanan online sesuai mode → teks marking → pencocokan dengan database IC → kandidat dan detail → verifikasi pengguna.

Catatan penggunaan

Hal penting agar data tetap akurat dan aman.

Hasil OCR perlu diperiksa

OCR dapat keliru membaca karakter mirip seperti 0/O, 1/I, dan 5/S. Pastikan marking fisik sesuai sebelum mengubah database atau nota.

Spesifikasi kosong berarti belum diverifikasi

Data kode dari tabel tidak otomatis menjamin RAM, BGA, atau protokol. Isi spesifikasi setelah mencocokkan dengan sumber teknis yang tepercaya.
